# Projeto Ford Focus Hatch Titanium 2.0 16V Flex Manual 2013 — Edição Única

Repositório estático autocontido com dossiê técnico, catálogo interativo de 50 equipamentos com imagens e galeria visual completa (25 vistas diurnas e noturnas) utilizando **IndexedDB** para armazenamento offline seguro no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório no seu GitHub (ex.: `projeto-focus-titanium-2013`).
2. Faça upload do arquivo `index.html` na raiz do repositório.
3. Acesse **Settings > Pages**, selecione a branch `main` e pasta `/ (root)` e clique em **Save**.
4. Seu painel estará acessível online e funcionará **100% offline** após o primeiro carregamento, salvando suas marcações de compra, instalação, valores pagos e anotações diretamente no banco local **IndexedDB** do dispositivo (com opção de exportar/restaurar backup `.json`).
